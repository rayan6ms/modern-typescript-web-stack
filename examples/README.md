# Example projects

Small projects created with the stack and kickoff skill. Each README explains how to run the project and what remains to be built.

| Project | What's included |
| --- | --- |
| [Cedar Journal](01-cedar-journal/README.md) | An Astro journal with responsive images |
| [DeskLedger](02-deskledger/README.md) | A TanStack Start app shell with PostgreSQL development tooling |
| [LiveBoard](03-liveboard/README.md) | A TanStack Start app shell with Convex configuration awaiting a deployment |

Copy a project into a new directory and follow its README. DeskLedger's local database setup uses rootless Podman.
